# Proposta: Biblioteca de Jogos

## Problema
Uma coleção ou biblioteca de jogos precisa de uma forma organizada de consultar o acervo, saber em qual plataforma cada jogo está disponível e controlar empréstimos e devoluções.

## Solução
Criar uma aplicação web para gerenciar jogos, gêneros e empréstimos. O sistema permite cadastrar e editar jogos, consultar o acervo e registrar retiradas e devoluções.

## Escopo
- CRUD de jogos.
- Cadastro e listagem de gêneros.
- Registro de empréstimos e devoluções.
- Indicadores de acervo e empréstimos ativos.

## Fora de escopo
Login, multas, reservas, notificações e integração com lojas digitais.

## Critério de sucesso
Os dados ficam persistidos no SQLite e as operações principais podem ser demonstradas pela interface.
